## ⚡ Overview

Every program includes verified eligibility criteria, grant sizes, direct portal links, and grounded primary documentation.

## 📦 Local Development

Clone the repository and serve the static files:

```bash
git clone https://github.com/NewSamBellamy/ai-startup-stack.git
cd ai-startup-stack
```

To run locally with Python:

```bash
python -m http.server 8000
# Open http://localhost:8000
```

To deploy to Cloudflare Pages:

```bash
npx wrangler pages deploy . --project-name omniveo-stack --branch main
```
