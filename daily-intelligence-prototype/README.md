# Daily Intelligence Brief — Prototype

A mobile-first prototype for a personalized daily intelligence product.

## Product idea
- 5 high-signal stories per day
- Plain-English explanations
- Simple / Deep reading modes
- Founder lens
- Source transparency
- Connect-the-dots synthesis
- Learning memory so future briefings build on prior concepts

## Prototype branch
prototype/daily-intelligence-brief

Open `daily-intelligence-prototype/index.html` in a browser to view the prototype.

This is a UI prototype with demo content. A production version would connect to a research pipeline that ingests trusted primary sources, major news outlets, selected newsletters, and podcast transcripts; deduplicates overlapping coverage; attributes expert commentary; and generates a structured daily brief.
